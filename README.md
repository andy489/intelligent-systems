### Tic-Tac-Toe

**Problem:** [PROBLEM](_exer/e-06-adversarial-search-(games)/TIC-TAC-TOE/PROBLEM.md) · [README](_exer/e-06-adversarial-search-(games)/TIC-TAC-TOE/README.md) · [SOLUTION](_exer/e-06-adversarial-search-(games)/TIC-TAC-TOE/SOLUTION.md)

Play Tic-Tac-Toe against an unbeatable computer opponent.
Solved with **Minimax + Alpha-Beta Pruning**:

- **Incremental winner detection** — checks only lines through the last-placed piece
- **In-place makeMove/undoMove** — no board copying during search
- **Depth-adjusted utility** — prefers faster wins and slower losses
- **Center bias** — equal-scoring moves default to center

The computer never loses; optimal play always results in a draw.

### Dots and Boxes

**Problem:** [PROBLEM](_exer/e-06-adversarial-search-(games)/DOTS-AND-BOXES/PROBLEM.md) · [README](_exer/e-06-adversarial-search-(games)/DOTS-AND-BOXES/README.md) · [SOLUTION](_exer/e-06-adversarial-search-(games)/DOTS-AND-BOXES/SOLUTION.md)

Play Dots and Boxes on an N×M grid against a computer opponent.
Solved with **Minimax + Alpha-Beta Pruning** with special handling for the extra-turn rule (closing a box grants another move):

- **Extra-turn correctness** — bonus turns keep the same player's perspective without decrementing depth, so chains of captures are fully evaluated
- **Move ordering** — box-closing moves tried first to maximise alpha-beta cutoffs
- **Heuristic** — scores unfinished positions by box difference plus sign-aware bonuses for 3-edge (capturable) and 2-edge (chain-opening) boxes
- **2×2 board**: exhaustive search — computer is provably optimal
- **3×3 board**: depth-7 search — full tree is infeasible (24! positions)

## E05 — Genetic Algorithms

**Problem:** Travelling Salesman Problem (TSP)  
**Docs:** [Slides-(2021-11-01)](_exer/e-05-genetic-algorithms/e-05-genetic-algorithms-slides.pdf) · [PROBLEM](_exer/e-05-genetic-algorithms/TSP/PROBLEM.md) · [README](_exer/e-05-genetic-algorithms/TSP/README.md) · [SOLUTION](_exer/e-05-genetic-algorithms/TSP/SOLUTION.md)  
**Data:** [data/](_exer/e-05-genetic-algorithms/TSP/data/) (UK-12 benchmark — 12 cities, optimal 1872.78)

Find the shortest closed tour visiting all N cities exactly once.
Solved with a **Genetic Algorithm** using permutation chromosomes:

- **Selection:** Stochastic Universal Sampling (inverted for minimisation)
- **Crossover:** Order XO (OX) · Two-Point XO · Cyclic XO — chosen at random
- **Mutation:** Inversion (2-opt) · Insert · Shuffle — equal probability
- **Elitism:** top 2 % carried unchanged each generation
- **Diversity:** random immigrant injection every 20 generations (10 % of worst replaced)
- **Termination:** 200 stagnation generations or 2 000 generation hard cap

Benchmark: **UK-12 dataset** (12 UK cities) — true optimal **1872.78**, found consistently with P ≥ 300.

## E04 — Constraint Satisfaction Problems

**Problem:** [N-Queens](_exer/e-04-constraint-satisfaction-problems/PROBLEM.md)  
**Docs:** [Exercise Sheet](_exer/e-04-constraint-satisfaction-problems/is-e-04-(2021-10-25).pdf) · [Slides-(2021-10-25)](_exer/e-04-constraint-satisfaction-problems/e-04-constraint-satisfaction-problems-slides.pdf) · [README](_exer/e-04-constraint-satisfaction-problems/README.md)

Place N queens on an N×N board so no two attack each other. Two independent solutions:

**1. Min-Conflicts (CSP / Local Search)** — places all N queens immediately then repairs conflicts iteratively. Expected O(N) time.

**2. Deterministic Linear Construction** — closed-form formula based on N mod 6; places every queen directly with no search and no restarts. Exact O(N) time.

## E03 — Informed (Heuristic) Search — IDA*

**Problem:** [N-Sliding Blocks Puzzle](_exer/e-03-informed-heuristic-search/PROBLEM.md)  
**Docs:** [Exercise Sheet](_exer/e-03-informed-heuristic-search/is-e-03-(2021-10-18).pdf) · [Slides-(2021-10-18)](_exer/e-03-informed-heuristic-search/is-e-03-informed-search-slides.pdf) · [Romania Map](_exer/e-03-informed-heuristic-search/romania-map.pdf) · [README](_exer/e-03-informed-heuristic-search/README.md)  
**Data:** [data/](_exer/e-03-informed-heuristic-search/data/) (162 puzzles: 2×2 through 10×10)

N-puzzle (8-puzzle, 15-puzzle, …): slide tiles on an N×N grid to reach the goal configuration.
Solved with IDA\* using **additive 5-5-5 disjoint pattern databases (PDB)** for the standard 4×4 puzzle, and **Manhattan Distance + Linear Conflict (MD+LC)** for all other grids:
- **PDB (4×4 canonical)** — tiles 1–15 split into three groups of 5; each PDB stores exact minimum moves for that group, summed for an admissible tight bound.
- **Manhattan Distance (MD)** — sum of each tile's row+col distance to its goal position.
- **Linear Conflict (LC)** — two tiles in their goal row/column but in reversed order must bypass each other, costing ≥2 extra moves not captured by MD. Added on top of MD for a tighter admissible bound.
